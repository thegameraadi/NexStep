# NexStep

**Your complete guide from application to orientation.**

A community-first platform for international students pursuing Masters, MBA, and PhD programs in the US. No ads. No upsells. Pure value.

## Tech Stack

- **Frontend:** React 19 + Tailwind CSS 3 + Vite 8
- **Routing:** React Router v7
- **Icons:** Lucide React
- **Hosting:** Vercel (free tier)
- **Database/Auth:** Supabase (coming soon)

## Platform Modules

1. **Roadmap** — Step-by-step timeline from research to arrival
2. **Programs** — Search 500+ MS/MBA/PhD programs
3. **Applications** — SOP guides, LOR templates, real breakdowns
4. **Finance** — Scholarships, loans, cost-of-living calculator
5. **Visa** — F-1/J-1 documentation, interview prep, wait times
6. **Pre-Departure** — Packing lists, banking, housing, insurance
7. **Community** — Real experiences from students who've been there

## Getting Started

```bash

```
